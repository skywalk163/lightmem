**环境**：FreeBSD 15.1 内置 PG 18，监听 `127.0.0.1:5432`，库 `lightmem_test`，表 `displacement_edges`。

```bash

# 2) 真机往返

  go test -run 'EdgePersistPg' -count=1 -v .
```

| 用例 | 覆盖 |
|---|---|
| `TestEdgePersistPgRoundTrip` | 建边 → Save → Load，有效边 3 / 软删边 1 / 四类 relation 计数 / 权重误差 ≤1e-9 |

| `TestEdgePersistPgDDLOnlyAdds` | DDL 只含 `CREATE`，不含 `ALTER`/`DROP`/`TRUNCATE`；四类 relation 在 CHECK 中 |
| `TestEdgePersistPgScopeIsolation` | 不同 scope 互不可见 |
