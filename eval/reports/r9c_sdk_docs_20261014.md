## 2. Python SDK 增强清单

### 2.1 版本升级

- 旧版本：`0.1.0`（R5-C 交付，stdlib-only，无重试/类型）
- 新版本：`0.2.0`（生产级增强）

### 2.2 新增功能

| 功能 | 实现 | 说明 |
|---|---|---|
| type hints | 全部公开方法添加类型注释 | 使用 `from __future__ import annotations` 支持 Python 3.7+ |
| 异常分层 | `LightMemError` → `LightMemConnectionError` / `LightMemAPIError` / `LightMemNotFoundError` | 含状态码和响应体 |
| 重试逻辑 | `_request` 内建重试（连接错误 / 5xx） | 默认 1 次，指数退避，4xx 不重试 |
| 上下文管理器 | `__enter__` / `__exit__` + `close()` | 支持 `with LightMemClient() as c:` |
| 向后兼容 | `LightMemClient(base_url, timeout)` 签名不变 | 新增 `retries` / `backoff_factor` 可选参数 |
| `__version__` | 模块级版本变量 | `0.2.0` |

### 2.3 代码变更

```diff
+ from __future__ import annotations
+ import time
+ from typing import Any, Dict, List, Optional, Tuple, Union
+ 
+ __version__ = "0.2.0"
+ 
+ class LightMemError(Exception): ...
+ class LightMemConnectionError(LightMemError): ...
+ class LightMemAPIError(LightMemError): ...
+ class LightMemNotFoundError(LightMemAPIError): ...
+ 
+ class LightMemClient:
+     def __init__(self, base_url="http://localhost:8080", timeout=10, retries=1, backoff_factor=0.5):
+     def __enter__(self) -> "LightMemClient": ...
+     def __exit__(self, ...): ...
+     def close(self) -> None: ...
+     def _request(self, method, path, payload) -> ResponseTuple:  # 含重试
```

## 9. 已知限制

1. **Python SDK 重试仅对连接错误和 5xx 生效**：4xx 属于客户端错误，重试无意义，直接抛出 `LightMemAPIError`。
2. **JS SDK 使用全局 `fetch`**：Node 18+ 原生支持；Node < 18 需 polyfill（不在本任务书范围）。
3. **OpenAPI 文档为手写**：未使用代码生成工具，与 `router.go` 路由表逐位对齐，但可能存在笔误。
4. **SDK 不处理认证**：LightMem 不依赖外部认证框架，认证通过请求体中的 `tenant_id` / `user_id` / `viewer` 字段实现。
