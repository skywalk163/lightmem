## 2. 建库脚本 `eval/scripts/r10_pg_setup.sh`

### 2.1 设计原则

- **凭据走环境变量**：`LIGHTMEM_PG_HOST/PORT/USER/PASSWORD/DB` 五变量，不硬编码；
- **测试库隔离**：库名 `lightmem_r10_test_<pid>`（pid 为脚本进程号），多轮测试互不污染；
- **可重复执行**：`create` 子命令先 `DROP DATABASE IF EXISTS` 再建，幂等；
- **清理子命令**：`drop` 一键删除测试库。

### 2.2 建表 DDL（memories）

列结构严格对齐 `kernel/backend_pg.go` INSERT/SELECT 列：

```sql
CREATE TABLE memories (
    memory_id            TEXT PRIMARY KEY,
    idempotency_key      TEXT NOT NULL,
    tenant_id            TEXT NOT NULL,
    user_id              TEXT NOT NULL,
    agent_id             TEXT DEFAULT '',
    project_id           TEXT DEFAULT '',
    visibility           TEXT NOT NULL DEFAULT 'private',
    shared_with_tenants  TEXT[] DEFAULT '{}',
    permission           JSONB DEFAULT '{}'::jsonb,
    permission_level     TEXT DEFAULT '',
    memory_kind          TEXT NOT NULL,
    fact                 TEXT NOT NULL,
    reference_frame      JSONB DEFAULT '{}'::jsonb,
    occurred_at          TIMESTAMPTZ,
    recorded_at          TIMESTAMPTZ NOT NULL DEFAULT now(),
    valid_from           DATE,
    valid_until          DATE,
    superseded_by        TEXT,
    confidence           DOUBLE PRECISION DEFAULT 0,
    source               TEXT DEFAULT '',
    version              INTEGER DEFAULT 1,
    importance           DOUBLE PRECISION DEFAULT 0,
    recent_access_score  DOUBLE PRECISION DEFAULT 0,
    access_count         BIGINT DEFAULT 0,
    expire_at            TIMESTAMPTZ,
    provenance           TEXT DEFAULT 'normal',
    source_evidence      JSONB,
    vector_status        TEXT DEFAULT 'pending',
    is_historical        BOOLEAN DEFAULT FALSE,
    goal_detail          JSONB,
    external_ref         TEXT,
    layer                TEXT DEFAULT '',
    feedback_records     JSONB,
    version_history      JSONB,
    embedding            vector(1024)
);
```

### 2.3 索引

```sql
-- 幂等键唯一索引（§4.1：(tenant, user, idempotency_key) 唯一）
CREATE UNIQUE INDEX IF NOT EXISTS idx_memories_idem ON memories (tenant_id, user_id, idempotency_key);

-- tenant 查询索引
CREATE INDEX IF NOT EXISTS idx_memories_tenant ON memories (tenant_id);

-- 向量 HNSW 索引（cosine ops，仅对已向量化的行建索引）
CREATE INDEX IF NOT EXISTS idx_memories_embedding_hnsw ON memories
    USING hnsw (embedding vector_cosine_ops)
    WHERE vector_status = 'vectorized';
```

### 2.4 用法

```sh
export LIGHTMEM_PG_HOST=localhost LIGHTMEM_PG_PORT=5432 \
       LIGHTMEM_PG_USER=postgres LIGHTMEM_PG_PASSWORD='' \
       LIGHTMEM_PG_DB=postgres

bash eval/scripts/r10_pg_setup.sh create   # 建测试库 + 建表 + 建索引
bash eval/scripts/r10_pg_setup.sh name    # 打印测试库名
bash eval/scripts/r10_pg_setup.sh drop   # 删除测试库
```
