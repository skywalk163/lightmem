## 二、A.2 漂移度量：三轴乘性衰减

**参考系三轴**：`entity` / `scene` / `task`（`DefaultDriftAxes()`），轴值取自
`ReferenceFrame` 与 `Memory.ReferenceFrame`，比较前做大小写/空白规整
（`driftNormalize`）。

**单轴判决**（`driftVerdictOf`）：

| 情形 | 系数来源 | 语义 |
|---|---|---|
| 两侧轴都非空且相等 | `Neutral = 1.00` | 对齐，不动 |
| 一侧含另一侧（部分匹配） | `Partial = 0.60` | 部分对齐，按部分匹配折算 |
| 两侧都非空且互不含 | **地板** `Floor = 0.15` | 漂移，下沉但不归零 |
| 任一侧缺失（空串） | `Neutral = 1.00` | **缺失即中性，不惩罚** |

**总系数**：三轴系数**相乘**（`driftScoreOf`），乘性衰减的固有性质是
**单轴漂移即把总分压到地板量级**，两轴/三轴漂移**仍停在地板、绝不低于地板**
（`TestDriftAllAxesDriftFloorNotZero`）。

**默认值**（`DefaultDriftConfig()`，保守缺省，先定后调）：

| 参数 | 默认 | 越界处理 |
|---|---|---|
| `Floor` | 0.15 | `<= 0` 回落默认；`> 1` clamp 到 1.0 |
| `Partial` | 0.60 | `< 0` 回落默认；`> 1` clamp 到 1.0 |
| `Neutral` | 1.00 | `< 0` 回落默认；`> 1` clamp 到 1.0 |
| `Axes` | entity/scene/task | 为空或全非法回落 `DefaultDriftAxes()` |

**三条契约**：

1. **只衰减不加分**：`DriftAwareRank` 输出分 = `recallScore × 系数`，恒 `≤ recallScore`
   （`TestDriftAwareRankNeverExceedsRecallScore`），不存在"漂移加分"。
2. **旁路算子**：`DriftAwareRank` / `DriftOf` 需调用方显式调用；
   `RankFusion.Rank` / `Fuse` / `VoteFusion` / `rrfRank` / `consensusVoteRank` 零改动，
   `kernel/rank_fusion.go` 逐字节未变（门禁 [7] `diff -q` 一致，
   `TestDriftDefaultPathUntouched` 亦断言默认路径不受影响）。
3. **结果不落库**：衰减只作用于本次返回序列，不写 `Memory`、不写 `StorageBackend`，
   因此不会污染 §4.2 的"元数据为事实源"骨架。

**确定性**：轴顺序固定、系数查表、无 map 迭代、无 `time.Now`、无随机；
`DriftAwareRank` 在召回分相同处按原输入顺序稳定输出（`TestDriftAwareRankDeterministicOrder`），
且**不修改入屏切片**（`TestDriftAwareRankDoesNotMutateInput`）。

## 三、A.4 两处测试断言自相矛盾的裁定（如实登记）

两处测试对 `Neutral = 0` 的要求相反：一处要求"零值回落到缺省 1.00"，另一处要求
"按地板 0.15 衰减"。按**保守契约取前者**：参考系缺失不得惩罚记忆。

理由：存量记忆中有大量历史条目**没有参考系**。若把"缺失"当作漂移，
这批记忆会被**集体打到地板**，直接威胁 M1 红线——而本轮红线就是 M1 不降级。
落地方式：`effectiveDriftCfg` 判定由 `< 0` 改为 `<= 0`（0 视为未设置，回落缺省），
契约写进 `DriftConfig.Neutral` 字段注释，避免下次又被改回。
