## 二、S5：FreeBSD jail vnet 修复（实机已执行）

### 1. 诊断到的三个叠加根因

| # | 根因 | 证据 |
|---|---|---|
| 1 | jail.conf 缺 IP 配置（无 ip4.addr / exec.start 配 IP） | jls IP 列空；jail 内 epairXb 无 inet |
| 2 | rc.conf 声明 `epair10~50` 与线上手工创建的 `epair0~4` 命名错位 | bridge0 桥接的 a 端与 jail 内 b 端 MAC 不配对；tcpdump 见 ARP 请求发出无应答 |
| 3 | bridge member a 端未显式 up | epair a 端 flags 缺 UP，二层帧不转发 |

### 2. 修复动作（0.88 实机，空壳 jail 无业务中断）

1. 备份 `/etc/jail.conf` → `/etc/jail.conf.r16bak`。
2. 停 5 个空壳 jail（内仅 syslogd/cron）。
3. 销毁命名错位的旧 `epair0~4`（a/b 都 destroy）。
4. 按 rc.conf 创建 `epair10~50`，bridge0 桥接 a 端并配 `10.0.10.1/24`。
5. 重写 `/etc/jail.conf`：`vnet.interface=epair10b~50b`，IP 由 `exec.start += ifconfig ... up; route add default 10.0.10.1` 配置。
6. 显式 `ifconfig epairXa up`（根因 3）。
7. `sysrc gateway_enable=YES`（jail→外网转发）。
8. 启动 5 个 jail。

### 3. 修复后实测连通性（0% loss）

- host → lims-pg (10.0.10.10)：0% loss
- host → lims-router (10.0.10.50)：0% loss
- lims-pg → host (10.0.10.1)：0% loss
- lims-pg → lims-router：0% loss

IP 分配：lims-pg=10.0.10.10、redis=20、rabbit=30、minio=40、router=50；宿主机 bridge0=10.0.10.1。

### 4. pf 规则复核

`pfctl -sr` 实机已合规：仅暴露 443/8443，SSH 限 `192.168.0.0/24`，其余 `block drop in on em0 all`。已把 `manuals/pf.rules` 管理网段从文档里的 `192.168.1.0/24` 修正为实机 `192.168.0.0/24`。
