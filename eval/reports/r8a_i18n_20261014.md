## 2. 关键设计决策（任务书 A.1 优先）

### 2.1 zh-CN 栏 = 真正的中文本地化（非英文原文）

**用户明确纠正**：「你不能直接把 zh-CN=英文，那样中文本地化就有问题！应该任务书优先！」

- **修正前**（错误）：zh 栏 = kernel 既有英文原文，以实现「默认态逐位不回归」。
- **修正后**（正确，任务书优先）：zh-CN 栏 = **真中文**，en-US = 英文，ja-JP = 日文，三语相互独立、逐语本地化。
- **不回归保障方式**（不再依赖 zh=英文）：kernel 既有错误/日志消息的英文硬编码**保持不动**（红线「只增不改」），i18n 化通过**新增**入口（`kernel/i18n_hook.go` + 样板函数）实现，不修改任何既有函数返回值/错误类型/日志格式，因此默认态行为**逐位不变**。

### 2.2 确定性词典（红线「不调 LLM」）

- 静态 slice + 线性查找（**非 map**），规避 map 迭代序/哈希随机源污染确定性。
- 无 `time.Now()`、无随机源；同 key 同 locale 同 args 恒等输出（测试 100 次恒等断言）。
- `Locale` 为 int 枚举，`Resolve(langTag)` 确定性解析：空串/空白→默认 zh → 精确标签 → 别名 → 大小写不敏感 → 主语言前缀（`zh-*`/`en-*`/`ja-*`）。

### 2.3 `%w` 占位符处理

`fmt.Sprintf` 不支持 `%w`。原设计翻译表含 `%w` 会 panic，故把 `%w` 从翻译表**移除**（`MsgScanFailed`/`MsgParseWeightsFailed` 改为纯文本/`%s`），接入时如需保留 wrap 语义，用 `fmt.Errorf("%s: %w", T(...), err)` 拼接。

### 2.4 回退链（不 panic、不空串）

1. locale 未知/非法 → `DefaultLocale`（zh-CN）；
2. key 未命中翻译表 → 返回 key 本身；
3. 占位符与 args 数量不匹配 → 返回未插值模板（`fmt.Sprintf` 天然容忍）。
