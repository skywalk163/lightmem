### 第 3 小时：BM25 占位实现增强（可选，若 R3 无效）

**前提**：若第 1 小时 R3 显示 keyword 权重提升无效，说明 `signalKeywordBM25` 占位实现真的只是返回 0。

**方法**：不引入 FTS5，用最简方式让 keyword 信号生效。

```go
// kernel/rank_fusion.go 中 signalKeywordBM25 占位实现
// 原实现（可能返回 0）：
func signalKeywordBM25(m *Memory, q string) float64 { return 0 }

// 新实现（词频匹配，零依赖）：
func signalKeywordBM25(m *Memory, q string) float64 {
    q = strings.ToLower(q)
    f := strings.ToLower(m.Fact)
    hit := 0
    for _, t := range strings.Fields(q) {
        if strings.Contains(f, t) {
            hit++
        }
    }
    if hit == 0 { return 0 }
    return math.Min(1.0, float64(hit)/float64(len(strings.Fields(q))))
}
```

**Token 预算**：
- 改代码：~200 tokens
- 0.88 跑 3 次：~0 tokens
- 验证：~50 tokens

**交付物**：
- `kernel/rank_fusion.go` 变更（1 个函数）
- BM25 生效后的分桶数字
