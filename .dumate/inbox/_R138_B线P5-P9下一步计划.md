## 二、P5 外部连接器

### 目标
按场景优先级接入外部数据源，支持引用式记忆与增量同步。

### 交付物
| 模块 | 文件 | 内容 |
|---|---|---|
| 连接器框架 | `kernel/connector.go` | Connector 接口定义、注册表、生命周期 |
| 数据库连接器 | `kernel/connector_db.go` | PostgreSQL/MySQL 增量同步、引用式记忆 |
| 文档连接器 | `kernel/connector_doc.go` | 文档解析、分块、向量索引 |
| 应用连接器 | `kernel/connector_app.go` | API 对接、Webhook 接收 |
| 引用式记忆 | `kernel/model.go` 扩展 | `ref_source`、`ref_target` 字段 |
| 增量同步 | `kernel/connector_sync.go` | 变更检测、冲突解决、背压处理 |

### 验收标准
- 数据库连接器支持增量同步（基于 WAL/时间戳）
- 引用式记忆可被检索链路正确解析
- 单次外部调用 300ms 软超时，降级为"仅内部记忆回答"
- 外部连接器故障不阻塞主路径

### 依赖
- P1~P4 全部完成 ✅
- 图数据库评估（按需，非阻塞）

## 三、P6 目标与共享

### 目标
GoalMemory 统一 Schema、权限三元组共享模型、撤销传播、管理后台。

### 交付物
| 模块 | 文件 | 内容 |
|---|---|---|
| GoalMemory | `kernel/goal.go` | Goal 记忆 CRUD、状态机、KPI 追踪 |

- 撤销传播 100% 完成（级联链路全部清除）
- 管理后台支持批量导入导出

### 依赖

## 八、关键决策点

| 决策点 | 触发条件 | 选项 |

| 图数据库引入 | 单租户向量行数 > 500 万 或 检索 P95 超红线 60% | Qdrant / Milvus / 暂缓 |

| 节点形态 | 部署规模 | 单节点 / 集合体 / 联邦共享 |

## 九、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 外部连接器不稳定 | 中 | 缓存、超时重试、降级内部记忆回答 |
| 权限越界 | 高 | 服务端强制校验 + 与 visibility 正交 |
| 撤销传播不完整 | 高 | 级联清除链路 + 审计 + 人工确认 |
| Qdrant 迁移复杂 | 中 | 双写过渡、`vector_status` 对账补偿 |
| 包生态碎片化 | 中 | 来源信任分级、包目录审核 |
