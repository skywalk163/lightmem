## 2. A 线（I-12）收口

### 根因
处理器 `handleSearch` 只读 `q`，而 `README.md` / MCP 桥发 `text` → `QueryParams.Text` 为空 → 后端跳过文本过滤（`if q.Text != ""` 为假）→ 任何串都返回该 tenant/viewer 作用域**全量**，分数恒定。

### 处置（仅 A 线文件域）
- `kernel/router.go` `handleSearch`：`q` 优先、`text` 兜底、空白裁剪；空查询返回 `400 {"error":"q or text required"}`；`tenant_id` 必填；无命中统一返回 `[]`（旧为 `null`）。
- 新增 `kernel/router_search_test.go`（14 用例）：q/text 命中等价、无匹配空集、空查询 400、q 优先、q 空回落、tenant 隔离、viewer 私有隔离、kind、top_k、大小写、空白裁剪。
- `README.md` / `docs/api.md` / `docs/api.openapi.yaml` / `sdk/python/lightmem_sdk.py` / `sdk/js/lightmem-sdk.js` / `integrations/dsh-mcp-bridge/lightmem_mcp_bridge.py` 参数口径与空查询语义同步。

### 验收（0.88，权威）
- `go test -run Search ./kernel/` 14/14 PASS。
- `go test -count=1 ./kernel/` 零回归。
- 真机：`q=`/`text=` 均按文本过滤、不存在串返回 `[]`、空查询 400；MCP 桥 `tool_search` 真机命中 1 条、不存在串 0 命中。
- 当时 `sh scripts/gate.sh` PASS 14 / FAIL 0 / SKIP 0（PG env 已配置，[11] 硬通过）。

## 3. B 线（I-15）收口

### 裁定
业主在决策门裁定走**方案 a：真 SQLite**（`modernc.org/sqlite v1.34.4`，纯 Go、无 cgo）。该方案**触红线⑦「不新增第三方依赖」**（R17 以来 grpc/protobuf 是唯一例外），由业主明确授权破例。

### 根因
`kernel/backend_sqlite.go` 原为**内存骨架**：`map[string]*Memory`，`path` 只赋值**从不用于任何 I/O**；进程一重启全部记忆丢失，`data/` 始终为空；`/health` 如实暴露后端名 `sqlite-skeleton/sqlite-vec`。

### 处置（仅 B 线文件域，与 A 线零重叠）
- **`kernel/backend_sqlite.go`**：内存骨架 → 真实 SQLite 持久化。
  - 单行表 `memories(memory_id TEXT PRIMARY KEY, data TEXT NOT NULL)` 存完整 `Memory` JSON。
  - `Upsert` 先 `SELECT data` 读旧版本号做幂等递增；同 `idempotency_key` 去重递增（`ON CONFLICT(memory_id) DO UPDATE SET data=excluded.data`）。
  - 所有过滤/排序在 Go 内完成，与内存骨架打分/排序语义一致，**零回归风险**。
  - 测试隔离：`nil`/空 `path` → `:memory:`（各实例天然隔离，仍是真实 SQLite）；显式 `path` → 文件 WAL 持久化。
  - 单连接 `db.SetMaxOpenConns(1)` + 全方法 `mu sync.Mutex` 互斥，避免 `database is locked`。
  - `Name()` 由 `sqlite-skeleton` → `sqlite`（去掉 skeleton 字样）。
- **`kernel/backend_sqlite_persist_test.go`**（新增，8 用例）：写入→Close→重开同路径→数据仍在；跨实例可见性隔离；幂等键版本递增；50 goroutine 并发写；GDPR 三件套重开后仍生效；Layer 扫描重开后仍生效；`VectorSearch` 仍降级；`Name()` 不含 skeleton。全部用 `t.TempDir()` 下显式文件路径 + WAL，**真实证明磁盘持久化**（非仅内存路径）。
- **`kernel/server_metrics_test.go`**：`/health` 后端名断言 `sqlite-skeleton` → `sqlite`。
- **`kernel/go.mod`/`go.sum` + `go.mod`/`go.sum`**：新增 `modernc.org/sqlite v1.34.4` 及传递依赖（root 经 `replace ./kernel` 进入构建图，`go.sum` 须同时补齐）。锁版本避开 `v1.60.1` 的 go≥1.26 toolchain 切换。
- **`profiles/lims-solo.profile.yaml`**：storage 段注明自 R19-B 起为【**真·持久化 SQLite**】；`vector_extension` 备注为占位（sqlite-vec 未接入）。
- **`lightmem.md`**：缺陷账新增 **L-217 关闭记录（R19-B，方案 a）**。

### 验收（0.88，权威）
- `go test -count=1 -run 'Persist' ./kernel/` **8/8 PASS**，且测试真实证明「**重建后端实例后数据仍在**」（写入→Close→重开同路径→数据仍在；并发 50 goroutine；GDPR / Layer 重开后仍生效）。
