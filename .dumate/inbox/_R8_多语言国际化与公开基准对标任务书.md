## 1. A 路 — P7-E 多语言国际化（`kernel/i18n/`）

### A.1 背景（根因）

roadmap §3.1 明确 **P7-E 多语言国际化（10-16~10-17）**为 confirmed 条目，交付物 `kernel/i18n/`，验收「国际化与本地化本轮完成」。当前状态：
- `kernel/i18n/` **目录不存在**（已核实）；
- 代码库无 i18n / 多语言框架（`grep -rliE 'i18n|多语言'` 仅命中 `sdk/README.md` 与 `eval/benchmarks/raw/beam.json` 的无关字符串）；
- kernel 内错误消息 / 日志 / 校验提示均为**硬编码中文**，无本地化钩子。

红线 4 明确「不调 LLM」——多语言国际化必须**确定性**：静态词典 + 键值表 + locale 选择，禁止翻译模型。

### A.2 范围与红线澄清

- **允许**：新增 `kernel/i18n/` 包（locale 类型、消息键枚举、静态翻译表、`T(locale, key, args...)` 函数）；`kernel/` 关键错误消息/日志接入 i18n 钩子（**只增**：新增 i18n 调用不改既有返回值语义）；新增多语言冒烟测试。
- **禁止**：调 LLM 翻译；改动既有函数返回值/错误类型语义（i18n 只影响文案，不影响程序行为）；改动 `Memory`/`RouterContext`/`RecalledCandidate` 字段。
- **约束**：`i18n` 包**确定性**（无 time.Now / 无随机 / 无 map 迭代序）；默认 locale 保持中文（不改变既有行为）；北极星 M1 / 公开 MRR 不回归。

### A.3 交付

1. **`kernel/i18n/` 包**：
   - `locale.go`：`Locale` 类型（`zh-CN` 默认 / `en-US` / `ja-JP` 示例）+ `Resolve(langTag string) Locale` 确定性解析。
   - `messages.go`：消息键枚举 + 静态翻译表（三语示例，覆盖 kernel 关键错误/日志/校验提示 ≥ 20 条）。
   - `translate.go`：`T(l Locale, key string, args ...any) string` + 回退链（key 未命中 → 中文原文，保证不回归）。
2. **kernel 接入示例**：`kernel/lifecycle.go` / `kernel/metrics.go` / `kernel/rank_fusion.go` 选 2–3 处新增 i18n 钩子调用（**只增**，不动既有返回语义），作为接入样板。
3. **冒烟测试** `kernel/i18n/i18n_test.go`：三语翻译、回退链、未知 locale、参数插值、确定性（同 key 同 locale 恒等）。
4. **报告**：`eval/reports/r8a_i18n_20261014.md`——设计（确定性词典）、覆盖消息键表、接入点清单、北极星/公开 MRR 不回归证明。
