# 光明记忆（LIMS）v2.3 — 智能记忆管理平台

> **让 AI Agent 像人一样拥有长期记忆**
> 多租户 · 多用户 · 多Agent · 可插拔后端 · 四层温度分层

---

## 一句话定位

光明记忆（Light Intelligent Memory System，简称 LIMS / 光明记忆）是一个面向多租户、多用户、多 Agent 的智能记忆管理平台。它让 AI Agent 像人一样拥有长期记忆、短期记忆和程序性记忆，并在不同场景下自动选择最合适的记忆层级进行存取。

---

## 核心价值

### 对 AI Agent
- **"记住"的能力**：不再每次对话都从零开始，新任务开始时能自动召回相关的历史目标、偏好和经验
- **个性化服务**：用户偏好、决策历史、项目上下文，跨对话持续沉淀
- **多跳推理**：从"客户A的决策人是谁"→"决策人偏好什么时间开会"，链式记忆自动桥接

### 对企业
- **知识资产沉淀**：客户、项目、流程等知识资产形成可复用的组织记忆
- **租户隔离可控**：租户/用户/项目/可见范围硬过滤，数据主权清晰
- **合规可审计**：每条记忆有完整溯源（来源、置信度、版本、时效）

### 对用户
- **个性化、连续的服务体验**：用户对自己的记忆资产有完整的查看、导出、删除入口（数据主权）
- **可控的遗忘**：低价值记忆自动淡化、压缩、归档，不无限膨胀

## 技术亮点

### 🧠 四层温度分层模型

| 层级 | 名称 | 类比 | 存储内容 | 生命周期 |
|---|---|---|---|---|
| **L0 工作记忆** | 人类短期工作记忆 | 当前对话上下文、核心记忆块、临时变量 | 分钟~小时 |
| **L1 动态记忆** | 人类情景记忆 | 用户偏好、近期事件、临时事实、跨Agent共享经验 | 天~月 |
| **L2 静态记忆** | 人类语义记忆 | 企业知识、产品文档、标准流程、长期目标/KPI | 长期版本化 |
| **L3 归档记忆** | 深层档案 | 历史会话原文、过期记忆、审计数据、合规保留数据 | 合规保留 |

### 🔍 多信号独立打分 + 名次融合（§3.4）

8 路信号**先独立打分，再按名次（rank）融合**，降低对权重先验的依赖：

| 信号 | 说明 |
|---|---|
| 语义相似度 | 向量召回分近似 |
| BM25 全文关键词 | 文本匹配 |
| 实体匹配 | 实体链接 |
| 固有价值 | 重要性 + 近期访问 + 置信度 |
| 时效新鲜度 | 指数衰减（半衰期 30 天） |
| 来源可信度 | 人工 > 系统 > 用户 |
| 参考系匹配度 | 空间/上下文坐标 |
| 反馈历史 | 采纳/弃用记录 |

> **关键设计**：冲突记忆不直接覆盖，而是通过多维加权融合，保留多版本。

### 🔒 安全与合规

- **投毒防护**：`provenance=prompt_injection_suspect` 标记 + 来源可信度上限 + 共享二次校验
- **记忆污染**：confidence 机制 + 低置信度待人工确认 + FeedbackLoop 修正
- **隐私保护**：租户/用户/项目/可见范围硬过滤 + 向量 pre-filter + 权限三元组
- **级联删除**：行使删除权后级联链路全部完成，可审计

### 📊 可插拔存储后端（§5.4）

| 后端 | 适用档位 | 状态 |
|---|---|---|
| **SQLite 骨架** | Solo（个人） | ✅ 已实现 |
| **PostgreSQL + pgvector** | Family / SMB / Enterprise | ✅ 已实现 |
| **Qdrant** | 迁移触发 | 🔜 规划中 |

## 快速开始

### 环境要求
- Go 1.25+
- 验证机：192.168.0.88（FreeBSD + ZFS 可选）

### 运行验证
```bash
# 克隆仓库
git clone http://192.168.1.5:3000/skywalk/lightmem.git

# 编译 + 测试
go build github.com/lightmem/kernel
go test github.com/lightmem/kernel/... -v

# 生成评测集 + 运行 KPI
cd eval
go run ./eval_generate.go
go run ./run_kpi.go
```

### API 端点
```
GET  /health          健康检查
GET  /profile        当前配置
POST /memories       写入记忆（走 WritePolicy）
GET  /search         文本检索
POST /search/vector  向量检索
POST /lifecycle/run  运行生命周期扫描
```

## 红线承诺

| 红线 | 承诺 |
|---|---|
| 1. 只增不改 Schema 语义 | 既有字段语义不变，新增字段只增不删不改 |
