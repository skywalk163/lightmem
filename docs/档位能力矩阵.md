## 三、能力边界声明（Solo 档）

> ⚠️ **R25-D 新增**：以下为 Solo 档的**真实能力边界**，不删 README 原有"零外部依赖"承诺，只补边界。

### 3.1 向量检索能力边界

| 状态 | 向量检索行为 | 依据 |
|---|---|---|
| **R25-B 前** | `/search/vector` 恒降级为文本检索（返回明确错误，由调度层降级） | `backend_sqlite.go:280` |
| **R25-B 后（R26 前）** | `/search/vector` 可用，纯 Go 暴力余弦（BLOB 存储），个人档数据量（数百至数千条）下性能足够；但全局 top-k 后才过滤可见性，双租户下少数派被多数派挤占（5% 503） | `kernel/sqlite_vector.go`（B 线新增） |
| **R26-B 后（当前）** | 余弦前按可见租户 `allowedIDs` 预筛（`SearchAllowed`），多租户语料下少数派不再被多数派挤占（R25 的 15×503 在 bench 中消失）；单租户 `allowedIDs==nil` 退回全局 `Search`，逐位一致、零额外开销 | `kernel/sqlite_vector.go:SearchAllowed` / `kernel/backend_sqlite.go:visibleMemoryIDs` |
| **R26-B 后（backfill）** | `BackfillVectors` 改为攒批（批大小 50）→ `PutBatch` 单事务 upsert，>800 条单次调用收敛（实测 892ms）、幂等（二次 `Vectorized=0`） | `kernel/sqlite_vector.go:PutBatch` / `kernel/backend_sqlite.go:BackfillVectors` |
| **不采用** | sqlite-vec（C 扩展/cgo）—— 与 `modernc.org/sqlite` 不兼容，且破 solo 零依赖承诺；**R26 已决策默认不做，备选路线待业主拍板** | §0.4 证伪结论 + R26 任务书 §0.5 |

### 3.2 零外部依赖承诺（保留，补边界）

README 原有承诺：
> "个人档默认 **SQLite，零外部依赖**（不用装 PostgreSQL / Docker）。"

**补注**：
- ✅ 零外部依赖：Solo 档仅需 SQLite 文件，无需 PG/Docker/Qdrant。
- ✅ 向量检索：R25-B 后纯 Go 余弦可用（BLOB 存储），仍零依赖。
- ❌ 无 jail / MAC / IPsec / KMS：Solo 档安全组件为极简形态。
- ❌ 无多租户 / 跨 Agent 共享：Solo 档为单用户形态。

## 八、运维说明（PG 门禁 env 固化，R26-A）

> 门禁 `[11]` PG 真机往返默认 SKIP（未配 env 不冒充 PASS，R15 口径）。要使其真实 PASS、达成门禁 **14/0/0**，需在验证机固化 PG env。

- **env 文件位置**：`/var/db/lightmem/gate.env`（0.88 验证机，**不入 git**，位于仓库工作树之外）
- **权限**：`chmod 600`（属主 `workbuddy`，仅属主可读写；目录 `/var/db/lightmem` 为 `700`）
- **内容**（实测，A 线交付态 md5 `0f6dc490…`）：
  ```sh
  export LIGHTMEM_PG_HOST=10.0.10.10
  export LIGHTMEM_PG_PORT=5432
  export LIGHTMEM_PG_USER=postgres
  export LIGHTMEM_PG_TEST_DB=lightmem_r26_gate
  ```
- **加载方式**：`scripts/gate.sh` 头部有一段**可选 hook**——文件存在则 `source`，不存在则保持原有 `SKIP: PG env not set` 语义。0.88 上**裸跑 `sh scripts/gate.sh` 即自动生效**（无需手工 source）；异地 checkout / CI / 生产机行为与 `82d31e0` 基线**逐字节一致**（实测日志 md5 相同），SKIP 不冒充 PASS，可移植性未破。删除该文件即回到 SKIP。
- **为何不入 git**：PG 主机/库/账号属敏感凭据，红线⑪要求 PG 凭据不入 git；0.88→PG 为 trust 免密，文件内**不含任何密码**，但仍按凭据管理（不入 git、600、工作树之外）
- **独立测试库**：`lightmem_r26_gate`（勿用生产库 `lims_dsh`，勿复用 `lightmem_r25_t0`）
- **实测结论**（A 线，2026-10-19）：`[11]` 由 SKIP 转 **PASS（真机往返 13 项全 PASS）**，收口态 **PASS 14 / FAIL 0 / SKIP 0**（R15 门禁矩阵引入以来首次 SKIP=0）
- ⚠️ **L-238（A 线新登记，待业主裁定）**：env 固化会激活根 module `eval/e2e/pg` 的 PG 用例（基线态 `t.Skip`），该套件在**有残留的测试库**上间歇 FAIL（`private` 可见性不校验 tenant + 同分并列 top-1 不确定）。收口态 14/0/0 须在**干净测试库第一跑**上达成；详见 `_R26_A线交付报告.md` §7
